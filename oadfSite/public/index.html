Open Archery Data Format

A directory of YAML and CSV for archery training. The same package is meant to be read by a person, a statistics tool, or a language model.

A package holds clubs, people, programmes, sessions, scores, equipment, sensor series, and photos. A zip is only transport: unpacking restores the same tree. The text of the specification is the contract. The worked package is the oracle.

A package

The root holds oadf.yaml. Every path inside a document is relative to that root. This tree is the shape; the names are an illustration.

Rules that stay fixed in version 1

  • Every YAML document starts with oadf: 1 and type.
  • A score that was not entered is omitted. M or 0 is a miss. A blank is not a miss.
  • Face plots use the centre as origin, +x right, +y up, and radius 10 at the outer edge.
  • Times are UTC with a Z suffix. Dates are YYYY-MM-DD.
  • Samples and photos stay in sidecar files. They are never inlined in YAML.
  • Unknown keys are kept and written back unchanged.

JSON with the same object shape is allowed. The file then ends in .json.
